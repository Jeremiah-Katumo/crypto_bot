# CryptoBuddy — Your AI-Powered Crypto Sidekick 🤖💸

Welcome to **CryptoBuddy**, a simple Python chatbot designed to help you navigate the wild world of cryptocurrency. Ask about trending coins, sustainability, investment tips, and get quick stats on popular cryptocurrencies.

---

## Features

- **Trending Cryptos:** Find out which coins are currently rising.
- **Sustainability Focus:** Learn which cryptos are eco-friendly with sustainability scores.
- **Investment Suggestions:** Get long-term and short-term investment ideas.
- **Coin Stats:** Request detailed info on Bitcoin, Ethereum, Cardano, and more.
- **Context Awareness:** Ask follow-up questions about previously mentioned coins.
- **User-Friendly Commands:** Type `help` for guidance or `exit` to quit anytime.

---
